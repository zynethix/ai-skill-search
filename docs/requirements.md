# AI Skill 搜索器 · 需求文档

## 产品定位

一个公开的只读网页，用于搜索 GitHub 上的 AI 技能（SKILL.md 技能包），帮助用户找到想要的技能。项目名：`ai-skill-search`。

## 已拍板决策

| # | 决策点 | 结论 |
| --- | --- | --- |
| 1 | 「AI skill」的含义 | SKILL.md 技能包（一个技能 = 一个带说明文件的目录，装进 agent 后教它做一类事） |
| 2 | 搜索交互方式 | 自然语言查询（两个输入框，分中英文） |
| 3 | 技能数据来源 | 自动爬取（GitHub） |
| 4 | 产品形态 | 静态网页，EdgeOne Pages 部署 |
| 5 | 爬虫运行方式 | GitHub Actions，每天定时一次；数据有变化才提交，无变化跳过 |
| 6 | 爬取源 | 聚合列表（awesome 类清单）起步；找不到满意结果时退到全 GitHub 搜索 |
| 7 | 条目展示信息 | 名称、一句话描述、来源仓库、安装方式、star 数、更新时间；全文可展开 |
| 8 | 搜索匹配 | 分语言的关键词检索（词面匹配），无机器翻译、无词表映射 |
| 9 | 界面语言 | 中文界面；技能名称/描述保留原文 |
| 10 | 技术栈 | Vite + React，构建产物纯静态 |
| 11 | 翻译/词表 | 不维护词表；用户自由输入，中英文各搜各的 |
| 12 | 站的使用对象 | 公开给所有人（无需登录、只读） |
| 13 | 实时重爬 | 先做 A 方案（跳 Actions 页由 owner 手动跑）；后续可升级 C（薄后端/边缘函数代触发） |
| 14 | 结果排序 | 相关度优先，相关度相同时按 star 数 |
| 15 | 敏感技能标记 | 全收录 + 卡片级「⚠️ 安全研究」标签，详情页补说明 |
| 16 | 项目命名 | ai-skill-search |
| 17 | 用户不满意的出口 | 公开用户走「报告缺失技能」（开 GitHub issue）；owner 手动跑爬虫 |
| 18 | 收录粒度 | 一条记录 = 一个 SKILL.md；一仓库多技能则出多条，共享仓库级 star/更新时间 |

## 功能点清单

1. **数据爬取**：爬虫抓取 GitHub 聚合列表中的技能仓库，逐条提取 SKILL.md。
2. **技能语言判定**：从 SKILL.md 正文自动判定技能是中英文；只收录中文、英文，其他语言暂不收录。
3. **数据文件**：爬虫产出 skills.json，随站点静态发布。
4. **定时更新**：GitHub Actions 每天跑一次爬虫，数据变化才提交新版本。
5. **双查询框**：英文框搜英文技能、中文框搜中文技能，各自独立、纯词面匹配。
6. **结果排序**：相关度优先，相关度相同时按 star 数降序。
7. **技能卡片**：展示名称、一句话描述、来源仓库、安装方式、star 数、更新时间；敏感类挂「⚠️ 安全研究」标签。
8. **技能详情**：点击卡片在站内展开全文；另有「查看源码」跳 GitHub。
9. **数据新鲜度提示**：站上显示「数据更新于 X 小时前」。
10. **报告缺失技能**：公开用户可开 GitHub issue 反馈缺失技能。

## 明确不做（v1）

- 不做账号/登录系统。
- 不做机器翻译、不做「中文词→英文词」对照表、不做语义搜索（embedding）。
- 不做自动「实时重爬」给公开用户（先走 owner 手动触发，C 方案后续再说）。
- 不收录中文、英文以外的其他语言技能。
- 不做内容隐藏（敏感类全收录，仅打标）。

## 验收标准

1. 站点是纯静态构建产物，可在 EdgeOne Pages 部署（命令须带 `-a overseas`）。
2. 爬虫能从聚合列表抓取技能并产出 skills.json，含名称/描述/来源仓库/安装方式/star/更新时间/语言。
3. GitHub Actions 定时（每天）跑爬虫，数据无变化时不产生新提交。
4. 英文框搜英文技能、中文框搜中文技能，结果按相关度优先、star 次级排序。
5. 技能卡片展示规定的六项信息；敏感类卡片带「⚠️ 安全研究」标签。
6. 点卡片在站内展开全文；有「查看源码」跳转 GitHub 的链接。
7. 站上可见「数据更新于 X 小时前」。
8. 公开用户有「报告缺失技能」入口（GitHub issue）。
9. 界面为中文，技能名称/描述保留原文。
